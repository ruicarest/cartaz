# Cartaz

A link-in-bio for live comedy & theatre artists — every date and ticket link in one place.

**Live demo:** https://ruicarest.github.io/cartaz/

This is a static, dependency-free prototype (single `index.html`) demonstrating the core idea:

- **Multi-faceted artist** — standup, improv and theatre under one link, filterable.
- **Collaborative events** — a show shared by several artists from one source.
- **Follow → get notified** — fans follow and get pinged about the next date (mocked with `localStorage`).

## Local preview

Just open `index.html` in a browser. No build step.

## Files

- `index.html` — the prototype (inline CSS + JS, mock data).
- `og.html` / `og.png` — the Open Graph share card and its rendered image.
